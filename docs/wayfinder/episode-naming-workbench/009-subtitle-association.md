# 确定字幕与视频的稳定关联规则

## Question

单集与合集任务中，如何综合下载器文件序号、目录、文件名解析集数和语言识别，把每个字幕稳定关联到唯一视频，并在结果存在歧义时避免错误跟随？

## Resolution

字幕关联只在同一下载任务内建立，并以“唯一可证明”为准：

- 下载器文件序号用于字幕自身的稳定身份，不作为它属于某个视频的证据；一个字幕最多关联一个视频，一个视频可以关联多个字幕。
- 优先使用字幕与视频解析出的类型、季度和最终集数进行精确匹配；若在任务内唯一，则允许字幕位于独立的字幕子目录。
- 无法解析集数时，仅当规范化文件主干在同一相对目录中唯一匹配，或任务只有一个视频且字幕没有解析出矛盾集数时才关联。
- 语言、文件列表顺序、文件大小、相邻序号和“目录里看起来最近”都不能单独建立关联，只用于已唯一关联后的字幕后缀与展示。
- 合集中出现多个同分候选、矛盾集数或无法识别时，字幕保持未关联并显示任务级异常；不得猜测跟随，也不阻止其他已确定命名单元应用。
- 用户可以把异常字幕明确指定给一个视频；人工关联写入计划修订并保持稳定，只有恢复缺省或明确重新关联才重新计算。
- 已关联字幕与视频共同预检、预留目标并按命名单元前向恢复；字幕目标保留语言或版本后缀，任何目标冲突都阻止该命名单元应用。
