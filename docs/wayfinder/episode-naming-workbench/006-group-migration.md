# 确定既有规则的番剧分组迁移策略

## Question

升级现有数据库时，如何把缺失年份、元数据不一致或同名不同作品的既有规则安全迁移到稳定番剧分组，并让不确定的归组结果可见且可纠正？

## Resolution

迁移以“不错误合并”为首要约束，并保持既有规则身份不变：

- 新增番剧分组及成员关系，不改写原 `bangumi.id`；下载器的 `ab:<id>` 标签、种子 `bangumi_id`、aria2 GID 关联继续指向成员规则。
- 仅当规范化正式标题、非空年份、季度和类型完全一致时自动归入同一分组；迁移键只用于首次归组，不成为分组的永久身份。
- 年份缺失、年份冲突、类型冲突或同名候选不唯一时，每条既有规则先建立独立分组，并记录待确认原因和候选分组；不得通过保存路径、字幕组或清晰度推断为同一作品。
- 用户可在页面中明确合并分组或移动成员规则；合并后空分组自动删除，历史下载和命名计划通过成员规则关系自然汇总。
- 迁移在单个数据库事务中幂等执行；失败整体回滚，重新启动可以安全重试，不在迁移期间访问 TMDB 或下载器。
