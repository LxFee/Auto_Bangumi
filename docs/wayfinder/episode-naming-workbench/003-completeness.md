# 确定命名字段的完整性与异常规则

## Question

当前命名方式或自定义模板引用哪些字段时才要求它们非空，哪些缺失允许省略，以及页面如何用最少的信息说明最终名称为何无法组合？

## Resolution

- 当前文件夹和文件命名规则共同声明字段需求：自定义模板显式引用的字段必须非空，经典命名方式固定使用的字段视为隐式引用。
- 引用字段为空即构成命名异常并阻止自动应用；未被当前规则引用的字段允许为空且不影响计划。
- 不引入额外的可选字段语法；希望字段可缺省时，应从当前模板中移除对应占位符。
- 字段值清洗后为空、数字字段无效、最终相对路径为空或不安全、目标名称被其他文件占用，均以统一的“异常”呈现。
- 页面只显示“异常”标记和可操作原因，例如“缺少：集数、字幕组”“番剧缺少年份”“目标名称无效”或“目标名称已被占用”，不增加错误级别和错误代码。
- 缺失的逐文件字段在当前行编辑；缺失的分组元数据或成员规则字段分别链接到番剧或规则编辑入口。
- 异常按媒体文件隔离：只阻止该视频及其匹配字幕，同一合集中的其他有效文件继续自动命名。
- 修正并应用异常文件时只处理该文件边界，不重新处理整个合集。
- 目标占用的具体处理与恢复行为留给“确定手动应用的原子边界与失败恢复”。
