# 确定番剧分组的稳定身份

## Question

跨多个订阅规则聚合剧集时，哪些领域字段共同定义同一个番剧分组，且在规则元数据被编辑后如何保持页面和命名计划的稳定归属？

## Resolution

- 新增具有稳定 ID 的番剧分组实体；规则、下载任务视图和命名计划通过该身份保持长期归属。
- 首次创建或迁移时，以正式标题、年份、季度和类型自动匹配分组；归组完成后，编辑这些元数据不会改变成员关系。
- 正式标题、年份、季度、类型、海报和放送信息属于番剧分组，所有成员规则和命名计划共享。
- 原始匹配标题、字幕组、分辨率、来源、字幕类型、RSS、过滤条件、季度偏移和集数偏移属于成员规则。
- 提供“移动规则”作为归组纠错操作：规则可移动到已有分组，或由该规则创建新分组；其关联下载任务和剧集随规则移动。
- 合并和拆分不设独立操作，均通过移动规则表达；最后一条规则移出后，空分组自动删除。
